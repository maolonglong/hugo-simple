# Hugo Simple Theme

A minimal, static Hugo theme with zero JavaScript: HTML templates plus CSS.

## Done means

- `just fmt` ran after template or style edits.
- `just check` and `just build` both pass. `check` only formats; `build` turns
  any Hugo warning (deprecation, missing translation) into a failure.
- The affected pages were rendered with `just serve` and inspected in light and
  dark.

## Conventions the tooling won't tell you

- Use semantic HTML5 with labeled landmarks and `aria-current` on navigation.
- `assets/simple.css` is vendored (refreshed weekly by `just update-simplecss`)
  and `assets/chroma.css` is generated by `just chroma`; edit neither. Theme CSS
  goes in `style.css`. `layouts/baseof.html` concatenates all three.
- Sites depend on the `custom_*.html` partials, the shortcodes, the i18n keys
  and the params. Renaming or removing one breaks them.
- Every new user-facing string gets a key in each `i18n/*.toml`.
- The minimum Hugo version is declared in `hugo.toml`, `theme.toml` and the
  README badge. Raise all three together, and only when a template needs the
  newer feature: it breaks users on older Hugo.
- A theme cannot set `markup.*` config. Settings that need it go in
  `exampleSite/hugo.toml` and the README.
- `just serve` and `just build` assume this checkout is named `hugo-simple`
  (`--themesDir ../..`).
